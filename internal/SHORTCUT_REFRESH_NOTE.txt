Shortcut bootstrap builds the Release Deadlimit Manager executable and recreates exactly two user-facing root shortcuts: Deadlimit Manager.lnk and Deadlimit Updater.lnk.

DeadlimitManager.cmd then marks every other root item Hidden+System so the checkout stays complete while normal Explorer view remains clean. DeadlimitUpdater.bat updates the entire repository from origin/main, refreshes the Manager build, and recreates the two shortcuts. Historical Deadlimit/Aggregator launchers remain only as hidden compatibility shims.
