# Deadlimit UI style

The current desktop theme should stay visually close to Source 2 tooling rather than stock high-contrast WinForms: low-contrast dark surfaces, restrained one-pixel borders, slightly lighter controls, and no bright framing around ordinary groups. The uploaded CSDK12 reference used during the 2026-08-23 UI pass is visual guidance only; Deadlimit keeps its own palette and layout.
