# Deadlimit

**Набор инструментов для художников, создающих моды для Deadlock.**

Deadlimit собирает основные этапы работы над модом в одном месте: помогает получить исходные ресурсы персонажа, подготовить модель и текстуры для Reduced CSDK, быстро проверять правки, собрать VPK и запустить мод в Deadlock.

Программа берёт на себя техническую рутину Source 2: поиск нужных файлов, исправление путей и ссылок в ресурсах, перенос файлов между инструментами и повторную подготовку проекта после изменений.

**Бесплатно · Открытый исходный код · Windows**

## Скачать

### Для художников

**[Скачать `Install-Deadlimit.cmd`](https://github.com/downlimit/Deadlimit/raw/refs/heads/main/Install-Deadlimit.cmd)**

Положите установщик туда, где хотите хранить Deadlimit, и запустите его.

Deadlimit создаст рядом с установщиком папку `Deadlimit` и установится в неё.

```text
D:\Tools\Install-Deadlimit.cmd
D:\Tools\Deadlimit\
```

Разбираться с Git или вручную настраивать .NET SDK не нужно. Если Git for Windows или .NET 10 SDK отсутствуют, установщик покажет, чего не хватает, и отдельно спросит разрешение на установку через WinGet.

Ранние сборки Deadlimit не подписаны цифровой подписью, поэтому Windows SmartScreen может показать предупреждение о неизвестном издателе. Запускайте только установщик с официальной страницы проекта `downlimit/Deadlimit` на GitHub.

### Для разработчиков

Если вы хотите изменять сам Deadlimit, исправлять ошибки или добавлять новые функции, скопируйте репозиторий через Git:

```powershell
git clone https://github.com/downlimit/Deadlimit.git
cd Deadlimit
.\DeadlimitManager.cmd
```

Для запуска из исходников требуется .NET 10 SDK. Правила отправки изменений описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

# Deadlimit Manager

**Deadlimit Manager** — основная программа и центр рабочего процесса.

### Проекты

Каждый мод хранится как отдельный проект Deadlimit.

Программа запоминает выбранного персонажа, рабочие файлы проекта и уже подготовленные данные, чтобы вам не приходилось каждый раз вручную собирать весь набор заново.

### Получение исходных ресурсов

Вы выбираете персонажа Deadlock, а Deadlimit получает из установленной версии игры нужные исходные модели, материалы и связанные ресурсы.

Вместо ручного поиска по игровым VPK вы сразу получаете основу для своего мода.

### Подготовка для CSDK

Кнопка **ПОДГОТОВИТЬ ДЛЯ CSDK** превращает ваши рабочие файлы в проект, который можно открыть в Reduced CSDK.

Deadlimit раскладывает файлы по нужным папкам, исправляет известные проблемы после экспорта, приводит в порядок пути, подготавливает модель и материалы и подключает текстуры.

После этого проект остаётся обычным редактируемым проектом CSDK: его можно открыть в ModelDoc, настроить материалы и шейдеры, сохранить изменения и продолжать работу.

### LIVE SYNC

**LIVE SYNC** нужен для быстрых правок во время работы.

CSDK можно оставить открытым. Deadlimit следит за изменениями модели, текстур и цвета вершин (Vertex Color) и переносит поддерживаемые правки в подготовленный проект автоматически.

Если изменение требует полной повторной подготовки, Deadlimit запускает её сам и не закрывает CSDK.

Вместо постоянного цикла «изменить → подготовить → скопировать → открыть заново» остаётся в основном «изменить → посмотреть результат».

Когда LIVE SYNC активен, на кнопке отображается его название и пульсирующий красный индикатор.

### Сборка для теста

Когда мод готов к проверке в игре, кнопка **СОБРАТЬ ДЛЯ ТЕСТА** выполняет оставшиеся технические шаги.

Deadlimit подготавливает свежую версию проекта, компилирует изменённые ресурсы Source 2, восстанавливает данные, которые связывают модель с анимациями персонажа, проверяет результат, собирает VPK и устанавливает его в Deadlock.

В итоге вы получаете готовую тестовую сборку без ручного повторения всех шагов упаковки.

### Импорт и ремонт существующих VPK

Deadlimit умеет открыть существующий `pak##_dir.vpk` как отдельный проект.

Такой проект не прогоняется заново через обычную подготовку модели. При сборке Deadlimit может сравнить данные, связывающие модель с анимациями, с актуальной версией Deadlock и исправить устаревшие или отсутствующие связи, пересобрать VPK и установить исправленный мод обратно.

Этот режим предназначен именно для модов, в которых после обновления игры перестали работать анимации. Он не пытается автоматически чинить любые возможные ошибки чужого мода.

### Управление внешними инструментами

Программа помогает держать в порядке внешние инструменты, которые нужны для создания модов Deadlock.

Он умеет найти установленный Deadlock, установить и проверить Reduced CSDK и DeadlockTools, а также использовать дополнительные утилиты вроде DepotDownloader, когда они нужны для конкретной операции.

# Deadlimit Scripts

**Deadlimit Scripts** — инструменты для работы с моделями Deadlock непосредственно в 3D-редакторе.

Сейчас в комплект входит версия на MAXScript для 3ds Max. Поддержка Blender запланирована в рамках того же набора инструментов.

### Bone Tools

После импорта DMX скелет Valve не всегда удобно выглядит для моделера.

Bone Tools помогают быстро привести кости в удобный рабочий вид: подогнать их длину и толщину под иерархию, исправить направление отображения и восстановить кости, случайно превращённые в Editable Poly, не ломая анимацию и привязку модификатора Skin.

### Vertex Color (цвет вершин)

Deadlimit Scripts упрощают работу с цветом вершин ещё до переноса модели в движок.

Можно переносить цвет между цветом объекта и Vertex Color, включать и выключать его отображение в окне 3D-редактора, а также переносить цвет вершин, материал и другие нужные данные с одного меша на другие.

Для быстрой проверки в CSDK Deadlimit Manager может автоматически подготовить материал, который показывает цвет вершин.

Если экспортёр DMX теряет цвет вершин, команда **Export Vertex Color FBX** создаёт рядом дополнительный файл `*_vertexcolor.fbx`. Во время подготовки Deadlimit автоматически находит его и возвращает цвет вершин в соответствующий DMX-меш.

### Inner Lineart

**Inner Lineart** позволяет использовать характерный контур Deadlock не только по внешнему силуэту модели, но и внутри самого дизайна.

Вы выделяете нужные рёбра и задаёте ширину линии. Deadlimit Scripts строит отдельную геометрию так, чтобы она работала по тому же принципу вывернутых полигонов, который используется для контура в Deadlock.

При необходимости новая геометрия сохраняет UV-развёртку, цвет вершин, материалы, положение и привязку Skin исходной модели.

Так можно добавлять графичные линии прямо в дизайн персонажа и видеть их в игре тем же способом, которым Deadlock рисует обычный контур модели.

# Deadlimit Shade

**В разработке.**

**Deadlimit Shade** предназначен для художников по текстурам, работающих в Substance 3D Painter.

Его задача — сделать изображение материала в Painter заметно ближе к тому, как этот материал затем будет выглядеть в Deadlock.

Сейчас прототип уже включает шейдеры для Painter, настройки под отдельных персонажей, предварительный просмотр контура, инструменты для анализа игровых материалов и текстур, а также панель, которая помогает применить нужные настройки к проекту Painter.

Предполагаемый путь работы:

```text
Substance 3D Painter
        ↓
Deadlimit Shade
        ↓
Deadlimit Manager
        ↓
Deadlock
```

Цель Deadlimit Shade — дать художнику достаточно точный предварительный просмотр, чтобы материалы можно было нормально оценивать ещё до переноса в игру.

## Как всё связано

```text
Исходные ресурсы Deadlock
        ↓
Deadlimit Manager
        ↓
3D-редактор + Deadlimit Scripts
        ↓
Substance 3D Painter + Deadlimit Shade
        ↓
Deadlimit Manager
Подготовка / LIVE SYNC / сборка для теста
        ↓
Reduced CSDK
        ↓
VPK
        ↓
Deadlock
```

Deadlimit Shade пока находится в разработке и для текущей работы с моделями не обязателен.

## Статус проекта

Deadlimit активно развивается вместе с Deadlock и инструментами Source 2.

Сейчас поддерживается Windows. Текущая версия Deadlimit Scripts предназначена для 3ds Max и написана на MAXScript. Поддержка Blender запланирована, а Deadlimit Shade находится в разработке.

Обновления игры и внешних инструментов иногда требуют изменений в Deadlimit. Точные проверенные версии находятся в [COMPATIBILITY.md](COMPATIBILITY.md).
